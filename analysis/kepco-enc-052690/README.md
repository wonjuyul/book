# 한전기술(052690) 급등 원인 분석 및 맞춤 예측

분석 기준일: **2026-08-26 종가 123,400원** (전일 대비 +13.63%, 2일 누적 +36.66%)

전체 리포트는 [`report.html`](./report.html)에 있다. 이 문서는 결론과 재현 방법 요약이다.

## 1. 왜 올랐나

**촉매**는 2026-08-24 한국경제 단독 보도 — 미국 정부가 한국 측(한수원·정부)에 웨스팅하우스(WEC)
지분 최대 20% 공동 인수를 제안했다는 내용이다. 8/25, 8/26 이틀 연속 원전주 전체가 급등했다.

**한전기술이 동종 중 가장 크게 오른 이유**는 이 종목 고유의 것이다.

| 근거 | 내용 |
|---|---|
| 설계는 가장 먼저 발주된다 | 원전 밸류체인에서 A/E(종합설계)가 선행 공정 |
| WEC의 병목은 인력 | WEC 대형원전 설계 인력 4,000~5,000명 → 미국·유럽 동시 진행 불가. 한전기술은 약 2,000명으로 최대 8개 프로젝트 동시 수행 이력 |
| 양쪽 인허가 경험 | AP1000·APR1400 미국 표준설계 인허가 경험 모두 보유 |
| 금액 | AP1000 종합설계 프로젝트당 약 3,000억원, 2기 기준 2,800억~7,000억원, 한국형 노형 직접 설계 시 1조6,200억원 (대신증권 추정) |

**수익률 귀속 분해** (β=0.82, 2년 일간 로그수익률 회귀)

| 일자 | 한전기술 | KOSPI | 두산에너빌리티 | 한국전력 |
|---|---:|---:|---:|---:|
| 2026-08-25 | +20.27% | +0.68% | +10.55% | +3.81% |
| 2026-08-26 | +13.63% | +0.97% | +6.32% | +6.42% |
| **2일 누적** | **+36.66%** | +1.66% | +17.53% | +10.48% |
| └ 시장요인 | +1.4%p | | | |
| └ 고유요인 | **+35.3%p (96%)** | | | |

**바닥이 낮았던 것이 절반이다.** 4/16 장중 198,000원 고점 → 7/29 장중 77,100원(−61%).
2분기 실적 부진(매출 1,033억 −2.7% YoY, 영업이익 30억), 한전 어닝쇼크, 지수 조정이 겹친 자리에
강한 촉매가 얹혀 반등 폭이 증폭됐다.

**상승의 질** — 거래량은 진짜(20일 평균의 6.9배, 거래대금 2,289억)지만,
외국인은 이틀간 순매도(소진율 15.13%→14.39%, 약 28.3만주)했다.
6/12 종가가 하루 +29.98% 뛰며 투자주의종목으로 지정된 이력도 있다(종가 거래량 비중 41.08%).

## 2. 네 개의 엔진 (모두 이 종목 자체 데이터로 적합)

| 엔진 | 방법 | 핵심 결과 |
|---|---|---|
| 1 | 조건부 이벤트 스터디 (4,110영업일) | "52주 고점 −30%↓에서 2일 +15%↑" 11건 → +20일 중앙값 **−5.4%**(승률 30%), +250일 **+2.5%**(56%) |
| 2 | GARCH(1,1) + 부트스트랩 잔차 MC | α=0.147, β=0.801, α+β=0.948, 반감기 13일. 현재 조건부 변동성 **연 135%**, 1년 누적 σ 76.5% |
| 3 | 5팩터 회귀 (이격도·낙폭·거래량·RSI) | 단기 표본외 R²≈0 (예측력 없음). 120일만 유효(OOS R² 0.047, IC 0.30) → 현재 예측 **−10.2%** |
| 4 | 밸류에이션 | 리버스 DCF: 현재가는 **10년 연 26.4% 이익성장**을 요구. 시총/수주잔고 2.36배(피어 3~5배) |

> 엔진 3의 결과를 숨기지 않았다. **이 종목의 단기 방향은 기술적 팩터로 예측되지 않는다.**

**모든 구간에서 P(상승) ≤ 45%다.** 기대수익률이 플러스인데도 그렇다 — 연 76%가 넘는 변동성에서는
중앙값이 기대값보다 한참 아래에 놓인다(변동성 드래그).
즉 *"오를 확률"이 아니라 "올랐을 때 크게 오른다"*에 베팅하는 자리다.

## 4. 장기 예측

**촉매 확률 트리 → 시나리오** (확률은 저자 추정, 컨센서스 아님)

| 시나리오 | 확률 | 2027E 영업이익 | 2027E EPS | 적용 PER | 12개월 목표주가 |
|---|---:|---:|---:|---:|---:|
| Bear (체코만·미국 무산) | 22% | 780억 | 1,727 | 40배 | **69,000** (−44%) |
| Base (체코+완도금일+국내 2기) | 59% | 1,100억 | 2,433 | 60배 | **146,000** (+18%) |
| Bull (+미국 AP1000 실수주) | 19% | 1,350억 | 3,009 | 85배 | **256,000** (+107%) |

- **확률가중 12개월 기대주가 149,900원 (+21.5%)**
- 중앙값 경로 112,700원 (−8.7%), 25~75% 구간 **72,200 ~ 176,300원**
- 참고: 증권사 목표가 160,000원(대신, 8/10) ~ 230,000원(LS, 5/11). 20만원 이상은 대부분 2분기 실적 발표 전 리포트다.

**2~3년** — Base 경로의 3년 CAGR은 **+1%**에 불과하다.
지금 가격은 "좋은 일이 상당히 일어난다"를 이미 지불한 가격이고,
초과수익은 **미국 시장 진입이 실제 수주로 확인될 때만** 나온다.
그 기대가 꺾이면 하방은 −40~−70%까지 열려 있다.

## 5. 이 예측이 틀리는 경로

- 딜은 아직 **"제안설"**이다. 한수원·산업부 공식 확정 없음, CFIUS 심사·가격 협상 잔존
- **도시바 선례**: 54억달러로 WEC 87%를 샀지만 원천설계·인허가·수출통제는 끝까지 미국 규제당국에 있었고 2017년 파산보호
- **지분투자 ≠ 수주보장**. 자본·시공만 대고 의사결정권은 못 갖는 구조면 AP1000 하청에 그친다. 손실분담 조항 미확정
- 2026 컨센서스 영업이익 744~819억을 맞추려면 **하반기에만 573~648억**(OPM 15% 이상)이 필요하다. 2분기 OPM은 2.9%였다
- TTM PER **131배** — 실적이 아니라 기대 위에 선 주가
- 유통물량이 얇다: 한전 외 1인 53.06% + 국민연금 10.43% + Van Eck 5.01% = **68.5% 고정**

**체크포인트**: 9~10월 완도금일 본계약 → 10월 말 3Q 실적 → **12월 12차 전력수급기본계획 확정** →
2026 4Q~ 웨스팅하우스 지분 구조 발표 → 2027 미국 AP1000 첫 설계 발주

## 6. 재현 방법

```sh
sh analysis/kepco-enc-052690/run.sh
```

표준 라이브러리만 사용한다(numpy·pandas 불필요). 원본 데이터는 `data/`에 커밋되어 있어
그대로 실행하면 리포트와 동일한 숫자가 나온다. 새 기준일로 다시 받으려면
`run.sh` 안의 `scripts/fetch.py` 줄 주석을 해제한다.

| 스크립트 | 역할 |
|---|---|
| `fetch.py` | 네이버금융 일별 시세 API에서 원본 수집 (052690 / KOSPI / 034020 / 015760) |
| `tech.py` | 이동평균·RSI·MACD·ATR·볼린저·실현변동성·왜도/첨도 |
| `model1.py` | 급등 귀속 분해(베타), 자기 종목 이벤트 스터디 |
| `model2.py` | 조건부 이벤트 스터디 (4개 조건 + 무조건부 기준선) |
| `model3.py` | GARCH(1,1) MLE 적합(Nelder-Mead 자체 구현), 변동성 기간구조 |
| `model4.py` | 5팩터 회귀 + 표본외 검증(2022~) |
| `model5.py` | 드리프트 시나리오별 몬테카를로 |
| `model6.py` | 피보나치·매물대·ATR 밴드·이동평균 |
| `val.py` | 멀티플·이익 시나리오·리버스 DCF·수주잔고 배수 |
| `final.py` | 촉매 확률 트리 + 통합 예측 분포 + 도달 확률 |
| `chartdata.py` | 리포트용 차트 데이터 생성 |

## 면책

공개된 시세·공시·언론 보도를 바탕으로 한 정량 분석 자료이며 **투자권유나 매매 추천이 아니다.**
시나리오 확률, 2027~2028년 이익 추정, 적용 PER은 저자의 가정이며 컨센서스가 아니다.
몬테카를로 결과는 과거 변동성 구조가 유지된다는 가정에 의존하고,
회귀모형의 표본외 설명력은 대부분의 구간에서 0에 가깝다 — 본문에 그대로 적어두었다.
투자 판단과 그 결과는 투자자 본인의 책임이다.
