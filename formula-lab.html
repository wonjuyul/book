거리 01

두 점 사이의 거리

좌표 두 개만 주어졌을 때. 사실 피타고라스 정리 그 자체입니다.

평면 AB = √(x2−x1)2 + (y2−y1)2
수직선 AB = |x2 − x1|   공간 √(Δx)2+(Δy)2+(Δz)2

A와 B를 끌어보세요. 직각삼각형의 두 변(가로·세로)이 항상 Δx, Δy이고 빗변이 거리입니다.

헷갈림 방지 빼는 순서는 아무래도 상관없습니다. 어차피 제곱하니까 (x2−x1)2 = (x1−x2)2. 대신 제곱근을 마지막에 한 번만 씌우는 것. √ 를 각 항에 따로 씌우면 틀립니다.
거리 02

점과 직선 사이의 거리

점에서 직선에 수직으로 내린 길이. 직선은 반드시 ax+by+c=0 꼴로 바꾼 뒤 대입합니다.

거리 d = |ax0 + by0 + c|√a2 + b2 원점에서 |c|√a2+b2

점 P와 직선 위의 두 점 L1, L2를 모두 끌 수 있습니다. 빨간 선이 항상 직선과 직각을 이룹니다.

헷갈림 방지
  • y = mx + n 꼴로 주어지면 반드시 이항해서 mx − y + n = 0으로. 이때 b = −1입니다.
  • 분모는 x, y의 계수만. 상수항 c는 분모에 절대 들어가지 않습니다.
  • 분자에는 절댓값. 음수가 나왔다고 거리가 음수일 수는 없습니다.
거리 03

원의 방정식 · 원과 직선의 위치관계

원은 "중심에서 거리가 r로 일정한 점들". 그래서 앞의 점과 직선 사이의 거리가 그대로 쓰입니다.

표준형 (x−a)2 + (y−b)2 = r2  →  중심 (a, b), 반지름 r
위치관계 d < r 두 점에서 만남  ·  d = r 접함  ·  d > r 만나지 않음
3
0.5
-1
헷갈림 방지
  • 중심은 부호를 뒤집어 읽습니다. (x+3)2+(y−2)2=25 → 중심 (−3, 2), 반지름 5(25가 아님).
  • 일반형 x2+y2+Ax+By+C=0은 완전제곱으로: 중심 (−A/2, −B/2), r2 = A2/4 + B2/4 − C.
  • 판별식으로 풀어도 같은 결론이 나옵니다. 거리 비교가 훨씬 빠릅니다.
비율 01

내분점 · 외분점

선분 AB를 m:n으로 나누는 점. 외분은 내분식에서 n에 마이너스를 붙인 것뿐입니다.

내분점 P mx2 + nx1m + n, my2 + ny1m + n
외분점 Q mx2 − nx1m − n, my2 − ny1m − n 중점 (x1+x2)/2 꼴
2
1
헷갈림 방지
  • m은 먼 쪽 좌표에 곱합니다. m:n이면 m은 x2에, n은 x1에. (A에 붙은 비율이 A에 곱해지는 게 아닙니다 — 대각선으로 곱한다고 외우세요.)
  • 외분점은 m>n이면 B 바깥쪽, m<n이면 A 바깥쪽. m=n이면 분모가 0 → 외분점이 존재하지 않습니다.
  • 중점은 내분점의 1:1 특수한 경우일 뿐입니다.
비율 02

비율로 길이 구하기

평행선이 보이면 닮음, 중선이 보이면 2:1. 도형 문제에서 길이를 "재지 않고" 구하는 방법.

평행선 DE ∥ BC ⇒ AD:DB = AE:EC,  DE = ADAB × BC
무게중심 AG:GM = 2:1 (꼭짓점 쪽이 2)    닮음비 k 길이 k · 넓이 k2 · 부피 k3
0.4
헷갈림 방지
  • 닮음비가 2:3이면 넓이비는 4:9. 넓이비를 그대로 길이비로 쓰지 마세요. 거꾸로, 넓이비가 9:16이면 길이비는 3:4(제곱근).
  • 무게중심은 꼭짓점에서 2, 대변 중점 쪽이 1. 헷갈리면 "무거운 쪽(꼭짓점)이 길다"로 기억.
  • 비례식을 세울 때 대응하는 변끼리 짝지어야 합니다. 그림에서 같은 각을 먼저 표시하세요.
방정식 01

근의 공식

인수분해가 안 될 때 쓰는 최후의 수단. 짝수 공식을 같이 쓰면 계산이 절반으로 줄어듭니다.

기본형 x = −b ± √b2 − 4ac2a 짝수 공식 (b=2b′) x = −b′ ± √b′2 − aca
1
-2
-3
헷갈림 방지
  • 분모 2a는 전체에 걸립니다. −b만 나누고 루트를 따로 두면 틀립니다.
  • 맨 앞은 ±b가 아니라 −b. b가 음수면 부호가 두 번 바뀌어 양수가 됩니다.
  • 루트 안은 b2−4ac. 4ac−b2가 아닙니다.
  • 짝수 공식은 분모가 2a가 아니라 a, 루트 안도 4ac가 아니라 ac입니다.
방정식 02

판별식

근의 공식의 루트 안만 떼어낸 것. 루트 안이 음수면 실수 범위에서 답이 없다 — 그게 전부입니다.

판별식 D = b2 − 4ac b=2b′일 때 D4 = b′2 − ac   해석 D>0 서로 다른 두 실근 · D=0 중근 · D<0 서로 다른 두 허근
-2

c를 올리면 포물선이 위로 올라갑니다. x축과 만나는 개수가 곧 실근의 개수, 그게 곧 D의 부호입니다.

상황D > 0D = 0D < 0
이차방정식의 근서로 다른 두 실근중근(하나)서로 다른 두 허근
포물선과 x축두 점에서 만남접함만나지 않음
원과 직선 (대입 후)두 점에서 만남접함만나지 않음
a>0인 이차부등식 >0x<α 또는 x>βx≠α인 모든 실수모든 실수
헷갈림 방지
  • "접한다" = 중근 = D=0. 이 셋은 완전히 같은 말입니다.
  • D/4를 쓸 땐 4로 나눈 값과 비교하는 것이지 부등호 방향이 바뀌지 않습니다. 부호 판정 결과는 D와 동일.
  • a=0이면 애초에 이차방정식이 아니라 판별식을 쓸 수 없습니다. "이차방정식이" 라는 말이 있으면 a≠0 조건을 먼저 챙기세요.
방정식 03

부정방정식

식은 하나인데 미지수는 둘. 그냥 풀면 해가 무수히 많지만, 정수·자연수 조건이 붙으면 답이 유한해집니다.

전략 좌변을 곱의 꼴, 우변을 상수로  →  ( )( ) = 상수  →  약수쌍 나열(구구단)
변형 공식 xy + Ax + By + C = 0  ⇒  (x+B)(y+A) = AB − C

헷갈림 방지
  • 정수 조건이면 음의 약수도 반드시 포함합니다. 3 = 3×1 = 1×3 = (−3)×(−1) = (−1)×(−3) — 네 쌍.
  • 괄호를 만든 뒤 원래 변수로 되돌릴 때 부호를 반대로. (x+5)가 3이면 x = 3 − 5 = −2입니다.
  • 변형 공식의 우변은 AB−C. 괄호 안 상수는 x 옆에 B(=y의 계수), y 옆에 A(=x의 계수)로 엇갈려 들어갑니다.
  • 조건이 없으면 해가 무수히 많습니다. 문제에 "정수", "자연수"가 있는지부터 확인하세요.
방정식 04

고차방정식 (삼차 이상)

"대입해서 0이 되는 값 찾기 → 조립제법으로 차수 낮추기 → 남은 이차식은 근의 공식". 이 세 단계가 전부입니다.

인수정리 f(α) = 0  ⇔  f(x)는 (x − α)로 나누어떨어짐
후보근 α = ± 상수항의 약수최고차항 계수의 약수

세제곱 공식

a3±b3 = (a±b)(a2∓ab+b2)

복이차식 (치환)

x4+x2+1 = (x2+x+1)(x2−x+1)

삼차 근과 계수

α+β+γ = −b/a,  αβγ = −d/a

헷갈림 방지
  • 조립제법에는 빠진 차수의 0도 반드시 써야 합니다. x3−7x+6 → 계수는 1, 0, −7, 6.
  • 왼쪽에 쓰는 수는 α 자체입니다. (x−2)로 나눌 때 −2가 아니라 2를 씁니다.
  • 후보근은 상수항의 약수 ÷ 최고차항의 약수. 순서를 뒤집지 마세요. 보통 ±1, ±2부터 넣어봅니다.
  • 삼차 이상은 실근이 하나뿐일 수 있습니다. 남은 이차식의 D<0이면 나머지 둘은 허근.
수열 01

시그마 계산

"1부터 n까지 더해라"의 줄임말. 공식 세 개와 성질 두 개면 대부분 풀립니다.

Σk = n(n+1)2    Σk2 = n(n+1)(2n+1)6    Σk3 = n2(n+1)24 = (Σk)2
성질 Σ(ak+b) = aΣk + bn  ·  Σc = cn
6
헷갈림 방지
  • Σc = cn입니다. 상수라고 그냥 c로 두면 틀립니다. n번 더하니까요.
  • 시그마는 곱셈에 분배되지 않습니다. Σ(ab) ≠ (Σa)(Σb). 덧셈·상수배만 분배됩니다.
  • 시작이 k=1이 아니면 Σk=3n = Σk=1n − Σk=12처럼 빼서 맞춥니다.
  • 항의 개수는 (끝) − (시작) + 1. k=3부터 k=10까지는 8개(7개 아님).
도형 01

정삼각형의 크기

한 변만 알면 전부 나옵니다. 뿌리는 30°-60°-90° 직각삼각형의 1 : √3 : 2 하나뿐.

높이 h = √32a    넓이 S = √34a2
내접원 r = √36a    외접원 R = √33a = 2r
6
헷갈림 방지
  • 높이는 √3/2, 넓이는 √3/4. 넓이는 ½ × a × h라서 높이의 절반이 됩니다. 4와 2를 바꿔 쓰지 마세요.
  • 넓이에는 a2, 높이에는 a. 차수를 확인하면 헷갈릴 일이 없습니다.
  • 정삼각형에서 무게중심 = 내심 = 외심이 한 점입니다. 그래서 R = 2r이고, 높이를 2:1로 나눈 것이 그대로 R과 r입니다.
