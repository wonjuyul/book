## 이 노트의 원칙

1. **분류문** — 하위 항목이 아니라 나눈 **기준(축)** 을 남긴다.
2. **정의문** — 조건으로 쪼개 번호를 매긴다. 오답 선지는 조건을 하나만 바꾼다.
3. **대립문** — 결론 말고 **쟁점 축**을 한 줄로. 개별 결론은 축에서 다시 만들어낸다.
4. **근거문** — "그렇게 보지 않으면 ~한 결과가 된다"는 귀류법. 그 이상한 결과가 정보다.

추상 명사(비신분자, 신분자)에는 즉시 사람을 대입한다. 예시는 정보가 아니라 원리 확인용이다.
